# 🌤️ Horizon - Weather App

A modern and responsive weather application that provides real-time weather information, hourly forecasts, and 5-day weather predictions for any city around the world.

## ✨ Features

* 🔍 Search weather by city name
* 📍 Get weather for your current location
* 🌡️ Real-time temperature updates
* 💧 Humidity information
* 🌬️ Wind speed details
* 📊 Atmospheric pressure data
* 🌡️ Feels-like temperature
* ⏰ Hourly weather forecast
* 📅 5-Day weather forecast
* 🎨 Dynamic weather-based UI
* 📱 Fully responsive design
* ⚠️ Error handling for invalid locations

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript (ES6+)
* OpenWeatherMap API
* Vercel

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/udaybhardwaj09/Horizon-the-weather-app.git
```

### Navigate to the project folder

```bash
cd Horizon-the-weather-app
```

### Create a config file

Add your OpenWeatherMap API key inside `script.js` or create your own configuration setup.

### Run the project

Simply open `index.html` in your browser.
